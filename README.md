# موقع معهد أبناؤنا في الخارج — ABNAUONA Institute

موقع ثنائي اللغة (العربية RTL افتراضياً + الإنجليزية LTR) بهوية مصرية فرعونية، مع نظام حجز من 4 خطوات يرسل الطلب كاملاً إلى واتساب.

**التقنية:** HTML + CSS + JavaScript خفيف بدون أي إطار أو مكتبات.
مولّد صفحات ثابتة صغير (Node.js، بدون أي `npm install`) يبني كل صفحة كملف HTML حقيقي لكل لغة → أفضل SEO، سرعة عالية، ويعمل على أي استضافة.

---

## 1) التشغيل

المتطلبات: **Node.js 18+** فقط.

```bash
npm run dev
```
يفتح الموقع على http://localhost:4173 ويعيد البناء تلقائياً عند تعديل أي ملف داخل `src/`.

| الأمر | الوظيفة |
|---|---|
| `npm run build` | بناء الموقع كاملاً داخل مجلد `dist/` |
| `npm run build:strict` | نفس البناء لكنه يفشل لو كان هناك نص ترجمة ناقص |
| `npm run dev` | سيرفر محلي + إعادة بناء تلقائية |
| `npm start` | سيرفر محلي فقط (بدون مراقبة) |
| `npm run images` | إعادة توليد الصور (يحتاج Python + Pillow + numpy) |

---

## 2) النشر

- **Netlify:** اربط المستودع — الإعدادات جاهزة في `netlify.toml` (أمر البناء `npm run build`، مجلد النشر `dist`). ملفات `_headers` و`_redirects` تُولَّد تلقائياً (كاش، أمان، صفحات 404 لكل لغة).
- **Vercel:** اربط المستودع — الإعدادات في `vercel.json`.
- **استضافة عادية (cPanel…):** شغّل `npm run build` على جهازك ثم ارفع **محتويات** مجلد `dist/` إلى `public_html`.

> قبل النشر على دومين مختلف عدّل `site.url` في `src/data/site.json` (يُستخدم في canonical وsitemap وOpen Graph).

## 4) خريطة الموقع

كل صفحة موجودة باللغتين: `/ar/...` و `/en/...` (والرابط `/` يوجّه تلقائياً للغة التي اختارها الزائر آخر مرة، أو العربية افتراضياً).

| الصفحة | الرابط |
|---|---|
| الرئيسية (Hero + إحصائيات + عدّاد + أقسام مختصرة) | `/ar/` |
| من نحن (القصة، الرؤية، الرسالة، القيم، لماذا نحن) | `/ar/about/` |
| المراحل الدراسية (مساري عربي/لغات + تفاصيل كل مرحلة) | `/ar/programs/` |
| الأنشطة | `/ar/activities/` |
| الرسوم (جدول تفاعلي + حاسبة + الإعلان الرسمي) | `/ar/fees/` |
| الخريطة الأكاديمية (بردية + ملفات ics) | `/ar/calendar/` |
| معرض الصور (تصنيفات + Lightbox) | `/ar/gallery/` |
| الحجز (معالج 4 خطوات) | `/ar/booking/` |
| صفحة الشكر (رقم الطلب + الخطوات + المستندات) | `/ar/booking/thank-you/` |
| الأسئلة الشائعة | `/ar/faq/` |
| الأخبار والإعلانات | `/ar/news/` |
| تواصل معنا (نموذج + خريطة) | `/ar/contact/` |
| سياسة الخصوصية / الشروط | `/ar/privacy/` · `/ar/terms/` |
| صفحة 404 فرعونية | أي رابط غير موجود |

ملفات مولدة تلقائياً: `sitemap.xml` (مع hreflang) · `robots.txt` · `manifest.webmanifest` · `/ar/calendar/<id>.ics` لكل موعد و`all.ics` لكل المواعيد.

## 5) تعديل الأسعار والمواعيد كل عام ★

كل الأرقام في ملف واحد: **`src/data/site.json`** — لا تحتاج لمس أي كود.

**الرسوم** (`fees.stages`) — كل صف مرحلة:
```json
{ "id": "p13", "program": "primary", "arabic": 5500, "languages": 6500, "booksPerTerm": 250 }
```
- `arabic` / `languages` = الرسوم السنوية لكل مسار · `booksPerTerm` = الكتب للترم الواحد
- `fees.extras` = اليونيفورم / التسجيل / حجز الباص
- `fees.transport` = أسعار المواصلات لكل إمارة

تتحدث تلقائياً في: جدول الرسوم، بطاقات المراحل، الحاسبة، معالج الحجز، الفاتورة، رسالة واتساب، والـ Schema.

**المواعيد** (`calendar.events`) — التاريخ بصيغة `YYYY-MM-DD` ويوم الأسبوع يُحسب تلقائياً:
```json
{ "id": "t2-start", "date": "2027-01-25", "type": "start" }
```
- `type`: `start` · `midterm` · `final` · `end` (يحدد اللون والأيقونة)
- عنوان كل موعد في `calendar.events` داخل `ar.json` و`en.json` بنفس الـ `id`.
- العدّاد التنازلي يختار تلقائياً أقرب "بداية" قادمة (العام أو الترم).
- عند العام الجديد: عدّل `site.academicYear`، والتواريخ، ونصوص السنة في ملفَي الترجمة (ابحث عن `2026/2027`).

**شريط الإعلان العلوي:** `announcement.enabled` للإظهار/الإخفاء، وغيّر `announcement.id` عند تغيير نص الإعلان ليظهر مجدداً لمن أغلقه.

**التواصل:** `contact` (واتساب الحجز، الهواتف، البريد، العنوان، الخريطة).

**الإحصائيات:** `stats` (سنوات الخبرة، الطلاب، المعلمون، الأنشطة).

**وسائل التواصل الاجتماعي:** `social` — أي رابط تضيفه يظهر تلقائياً في الفوتر وفي Schema.

**Google Analytics و Meta Pixel:** ضع المعرّفات في `analytics.googleAnalyticsId` (مثل `G-XXXXXXX`) و`analytics.metaPixelId`. مع `requireConsent: true` يظهر شريط موافقة ولا تُحمّل الأدوات إلا بعد الموافقة. يُسجَّل حدث `generate_lead` / `Lead` عند إرسال طلب حجز.

**الخريطة:** للحصول على موقع دقيق للمعهد ضع `lat` و`lng` (من Google Maps → كليك يمين على الموقع) أو رابط المكان في `placeUrl`.

## 6) تعديل النصوص وإضافة محتوى

كل النصوص في `src/i18n/ar.json` و`src/i18n/en.json` (نفس المفاتيح في الملفين — البناء يحذّرك لو اختلفا).

- **خبر جديد:** أضف عنصراً في `news.items` في الملفين:
  `{ "id": "open-day", "date": "2026-10-10", "tag": "events", "image": "facade-day", "title": "…", "text": "…" }`
  (الأخبار تُرتب تلقائياً من الأحدث، و`image` اسم صورة من `images` في site.json أو احذفه).
- **سؤال شائع:** `faq.items` (`q` و`a`) — يُضاف تلقائياً لـ FAQ Schema.
- **رأي ولي أمر:** `testimonials.items`.
- **عناوين ووصف SEO لكل صفحة:** `pages.<id>.title` و`description`.

## 7) الصور ★

الصور الحالية مأخوذة من الملفات التي أرسلتها (بعد ضغطها إلى WebP بأحجام متعددة):

| الاستخدام | الملف |
|---|---|
| خلفية الـ Hero + صورة المشاركة | الواجهة ليلاً `facade-night` |
| من نحن / الأخبار | البوابة نهاراً `facade-day` + تفاصيل البوابة `gate-detail` |
| الأعمدة المضيئة | `corridor` + `column-detail` |
| حفل التخرج | `graduation-2025` |
| الإعلانات الرسمية | `poster-fees` · `poster-calendar` |
| الشعار | مستخرج من إعلان الرسوم ومعاد رسمه بالذهبي والبني |

### صور يجب استبدالها قبل الإطلاق
1. **صور الأنشطة والحفلات في المعرض** — حالياً لوحات توضيحية مولّدة (`ph-drawing`, `ph-music`, `ph-sports`, `ph-trip`, `ph-celebration`, `ph-national-day` في `gallery` داخل site.json). استبدلها بصور حقيقية:
   ضع الصورة في `assets/`، أضفها في `PHOTOS` داخل `scripts/optimize-images.py`، شغّل `npm run images`، أضفها في `images` داخل site.json، ثم في `gallery` استبدل `"placeholder": {...}` بـ `"image": "اسم-الصورة"`.
2. **صورة حفل التخرج** بدقة أعلى (الحالية 680px فقط).
3. **الشعار الأصلي بصيغة SVG/PNG عالية الدقة** — الحالي مستخرج من صورة صغيرة. ضعه في `src/assets/img/brand/` بنفس الأسماء (`logo-mark-brown-*.webp`, `logo-mark-gold-*.webp`) أو عدّل المسار في `layout.js`.
4. (اختياري) صورة Open Graph مخصصة `src/assets/img/brand/og-image.jpg` بمقاس 1200×630.

## 8) محتوى يحتاج مراجعة من الإدارة قبل النشر

- **الإحصائيات** (`stats`): 5+ سنوات، 500+ طالب، 35+ معلم، 12+ نشاط — أرقام مبدئية، عدّلها للأرقام الحقيقية.
- **آراء أولياء الأمور** (`testimonials`): نماذج توضيحية — استبدلها بآراء حقيقية (بإذن أصحابها).
- **تواريخ الأخبار** (`news.items`): تاريخ فتح التسجيل وإعلان الخريطة وحفل التخرج تقديرية.
- **قائمة المستندات المطلوبة** (صفحة الشكر + الأسئلة الشائعة) وإجابة سؤال الامتحانات مع السفارة: صيغت بشكل عام — راجعها.
- **سياسة الخصوصية والشروط:** قوالب قابلة للتعديل — يفضّل مراجعتها قانونياً.
- **روابط السوشيال ميديا** و**معرّفات التحليلات** و**إحداثيات الخريطة**: فارغة حالياً.

## 9) كيف يعمل نظام الحجز

1. **الباقة:** بطاقات المراحل (KG / 1-3 / 4-6 / إعدادي / ثانوي) + مسار عربي/لغات → السعر يظهر فوراً.
2. **الخدمات:** المواصلات (تُضاف رسوم حجز الباص 200 تلقائياً)، اليونيفورم (مفعّل افتراضياً)، الكتب (ترم/ترمين)، كاش/تقسيط.
3. **البيانات:** تحقق فوري من كل الحقول برسائل واضحة باللغة الحالية.
4. **الإرسال:** فاتورة مبدئية + رقم طلب `ABN-YYYYMMDD-XXXX` + زر يفتح `wa.me/971555515049` برسالة جاهزة بالصيغة المطلوبة، ثم صفحة الشكر.

- البيانات تُحفظ على جهاز الزائر أثناء التنقل (حتى 3 أيام) وتبقى حتى عند تبديل اللغة، ويمكن مسحها بزر.
- حاسبة الرسوم وأزرار "احجز في هذه المرحلة" تملأ المعالج مسبقاً عبر الرابط (`/ar/booking/?stage=p13&track=languages&transport=dubai`).
- لا يوجد سيرفر أو قاعدة بيانات: لا تُخزَّن بيانات أولياء الأمور على الموقع.

## 10) الجودة

- Lighthouse (موبايل، على السيرفر المحلي مع ضغط gzip): الأداء 96–100 · الوصول 100 · أفضل الممارسات 100 · SEO 100.
- SEO: عنوان ووصف لكل صفحة باللغتين، canonical، hreflang، Open Graph/Twitter، Schema.org (`EducationalOrganization` + `LocalBusiness`، `BreadcrumbList`، `FAQPage`، `NewsArticle`، `Course`)، sitemap.xml، robots.txt.
- الوصول: رابط تخطٍ، تنقل كامل بلوحة المفاتيح، نصوص بديلة، تباين ألوان كافٍ، احترام `prefers-reduced-motion`.
